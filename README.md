# Empire & Kin

Prohibition NYC mob game. GTA action + Sims life + City Builder.

**Stack**: Zig + Magister + Arcis + RealCity

**Phase 2**: Crew simulation, healing (safehouses + food + prostitution entertainment), rackets.

**Phase 3**: Combat system + Missions (bootlegging, protection, hits, heists, smuggling).

**Phase 4**: City districts, crew management, economy loop.

**Phase 5**: Events, police raids, rival families, save/load.
