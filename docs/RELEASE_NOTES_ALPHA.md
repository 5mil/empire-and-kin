# Empire & Kin 0.1.0-alpha

**Date:** 2026-07-24

## What's in

- Real-time NYC mob simulation foundation (1930s / 1980s eras)
- Free-roam player, districts, economy, crew, rackets
- Empire pause UI (properties + vehicle garage)
- Multi-job world markers with payout and heat
- Wanted / police pursuit feedback
- Live random events and rival control pressure
- Street combat encounters (stub)
- Disk save/load (`empire_save.txt`)
- Boot title + era select
- Onboarding hints

## Stack

Zig · engine.Backend abstraction · NullBackend (headless)  
Target renderers: Magister · Arcis · RealCity

## Not in alpha

Full 3D rendering, PD art integration, audio, streaming map
